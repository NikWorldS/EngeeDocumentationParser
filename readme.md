# Engee Documentation Parser
Парсер позволяет скачать документацию блоков, а также суммаризировать текст.

Работает поэтапно:
- парсинг ссылок
- установка файлов
- суммаризация скачанных файлов

Перед парсингом есть возможность выбрать определённые библиотеки. При выборе будут скачиваться описания блоков 
определённых библиотек (в базовой настройке скачиваются все библиотеки)

Все установленные файлы (при запуске из `main.py`) сохраняются в папке `runs/`. Внутри создаются папки для каждого запущенного рана (с названием в формате `datetime-time` на момент запуска).
Скачанные доки сначала сохраняются в папке `documentation` (внутри папки текущего рана). Суммаризованные файлы сохраняются в папке `converted_docs` (также внуртри папки текущего рана).


### Запуск
Без API ключа парсер не будет запущен.

Перед парсингом будет предложен выбор библиотек. Чтобы выбрать все, нужно вписать `all`, а для выбора определённой - 
ввести индексы библиотек через пробел.

## Parser/Downloader
При скачивании файлов из текста убираются заголовки "примеры", "дополнительные возможности", "смотрите также".


## Converter
> Для работы конвертера (суммаризатора) в Markdown нужен API-ключ от [OpenRouter](https://openrouter.ai/keys).
> В `.env` необходимо сохранить полученный API_key (пример в `.env.example`)
